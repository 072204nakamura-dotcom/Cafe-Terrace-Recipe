レシピ管理システム　使い方

はじめに レシピ 原価の見方 食材マスター 保存と同期 困ったとき
🚀

はじめに（最初の1回だけ）

スマホでこのシステムを開いて、最初に1回だけ設定をします。

  1. 店から送られたURLを開く
  2. 右上の ☁️ クラウド設定 を押す
  3. 店から送られたもう1つのURL（script.google.com で始まるもの）を貼り付けて OK
  4. 下の 🔄 同期 を押す → 食材とレシピが出てくれば完了
ホーム画面に置くと便利です。
iPhoneのSafariで開いて、下の「共有」→「ホーム画面に追加」。アプリのように開けます。

画面は3つのタブに分かれています

  • 📖 レシピ … レシピの登録・原価の確認（みんなが使います）
  • 🧂 食材マスター … 食材の値段の一覧（見るだけ）
  • 📷 納品書 … 納品書から値段を取り込む（店主だけ）
📖

レシピを登録する

  1. 下の ＋ レシピ追加 を押す
  2. レシピ名とカテゴリを入れる
  3. 「食材・原材料」の ＋ 追加 を押す
  4. 食材を選択… を押すと検索画面が開く。カテゴリで絞るか、文字を打って探してタップ
  5. 量を入れる（単位は自動で入ります）
  6. 材料を全部入れたら 💾 登録する を押す
食材を選ぶと単位と歩留まりが自動で入ります。原価は入力しながらその場で計算されます。

分量の書き方

  • 必ず g（グラム）か ml で入れてください
  • 卵など「個」で数えるものは「個」のままでOK
  • 「少々」「適量」は計算できないので、だいたいの数字を入れてください

基準量・仕上がり率・1人前量

欄入れるもの
基準量出来上がりの総量。材料から を押すと自動計算
仕上がり率煮込んで減る分。煮込み50％／軽い煮込み70〜80％／生100％
1人前量1皿に使う量。入れると「何人前とれるか」が出ます
煮込み料理のコツ。仕上がり率を50にして 材料から を押すと、材料合計の半分が基準量になります。実際に出来上がりを計ったことがあれば、その数字を手で入れるのが一番正確です。

レシピを直すとき

  1. レシピをタップして中身を表示
  2. ✎ 編集 を押す
  3. 直したら 💾 保存する
💰

原価の見方

表示意味
税抜原価材料費の合計（このレシピ全部ぶん）
税込原価上に消費税8％を足したもの
1人前あたり1皿ぶんの材料費。売価を決めるときはここ

歩留まりとは

皮や骨を取ると使える量が減ります。その分を上乗せして計算する仕組みです。

鶏もも肉 ¥1.0/g・歩留まり85％
→ 実際に使える1gの値段は ¥1.18（¥1.0 ÷ 0.85）

食材マスターに登録済みなので、基本はさわらなくて大丈夫です。下処理の仕方が違うときだけ、レシピの「歩留％」欄を直してください。

🧂

食材マスター（見るだけ）

食材の値段は店主が管理しています。スタッフは値段を変えたり保存したりしないでください。見るだけ・探すだけでお願いします。
  • 上の検索欄に食材名や業者名を入れると絞り込めます
  • カテゴリーのボタンでも絞り込めます
  • 食材をタップすると、仕入単価・歩留まり・業者が見られます

「この食材が無い」「値段が違う気がする」と思ったら、自分で直さずに下のご意見箱から知らせてください。

🔄

保存と同期のルール

これだけは覚えてください。
開いたら 🔄 同期　／　直したら 💾 保存

なぜ必要なの？

  • 同期＝他の人が入れた最新のレシピを受け取ること
  • 保存＝自分が入れたレシピをみんなに渡すこと
  • 保存しないと、自分のスマホの中だけに残って他の人には見えません
直したのに保存せずに同期すると、自分が直した内容が消えます。必ず「保存 → 同期」の順で。
❓

困ったとき

レシピが出てこない
下の 🔄 同期 を押してください。それでも出ないときは、電波の良いところでもう一度。
入れたレシピが他の人に見えない
保存を押し忘れていませんか。レシピを開いて 💾 保存する を押してください。
原価が ¥0 と出る
材料が入っていないか、量が0のままです。材料と量を入れてください。
使いたい食材が見つからない
検索は短い言葉のほうが見つかります（「熟成鶏もも肉」より「鶏」）。それでも無ければご意見箱へ。
ボタンを押しても反応しない
ページを再読み込みしてください（画面を上から下に引っぱる）。
まちがえて消してしまった
自分で直そうとせず、すぐ店主に伝えてください。直せることが多いです。
